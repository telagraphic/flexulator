# NumberFlow owns read-only numbers; form controls stay native

Read-only calculator numbers (Measured Width, Item Card formulas, teaching panels) may become NumberFlow hosts painted through the same `data-field` path. Grow / Shrink / Basis on the Add form and on Item Cards stay native `<input type="number">`, labeled for keyboard and sighted use. NumberFlow never sits inside those labels, and `<number-flow-group>` wraps only rolling numbers — not the input cluster or Remove. A later overlay may decorate an idle input, but typing still uses a real input; paint does not invent a second selector vocabulary. Semantic markup ships before NumberFlow so labels land first. Plans: [semantic-control-markup.md](../semantic-control-markup.md), [prd-numberflow.md](../prd-numberflow.md).
